# AadiVed Yoga and Wellness: website

Marketing site for AadiVed Yoga and Wellness, a women-owned yoga and sound healing studio in Hinjawadi Phase 3, Pune. Built with Astro 5 (static output), plain CSS and a small vanilla script for the menus.

## Commands

| Command | What it does |
| --- | --- |
| `npm install` | Install dependencies |
| `npm run dev` | Dev server at http://localhost:4321 |
| `npm run build` | Build to `dist/` |
| `npm run preview` | Serve the built site |
| `npm run check:dist` | Fail if `dist/` has any `.jpg/.jpeg/.png/.avif` other than the allowed exceptions |
| `npm run assets:generate` | Regenerate the favicon, touch icon, manifest icons and OG image in `public/` |

Run `npm run build && npm run check:dist` before every release.

## Where things live

- `src/data/site.ts`: phone, address, socials, Google links, navigation, mega menu, footer links and the registry of stub pages. Components never hard-code these.
- `src/data/services.ts`, `src/data/reviews.ts`: homepage service cards and Google reviews.
- `src/pages/index.astro`: homepage. `src/pages/[...slug].astro` generates every other route from `stubPages` in `site.ts`.
- `src/scripts/menu.ts`: mega menu, About dropdown and mobile nav behaviour.
- `design-source/`: the original PNG/JPG files. Not built, not deployed.
- `reference/homepage-mockup.dc.html`: the approved homepage design.

## Image format rules

Every image on the site is WebP, rendered through `astro:assets` with `format="webp"` and explicit dimensions.

**Exceptions (the only non-WebP files in `dist/`)**, all generated by `scripts/generate-icons.mjs` from the vector logo masters in `design-source/` (`aadived-favicon-source-512.webp` for the icons, `aadived-logo-square-olive-2048.webp` for the OG image):

- `og-image.jpg` (1200x630): WhatsApp, Facebook and LinkedIn previews often ignore WebP
- `favicon.ico`
- `apple-touch-icon.png` (180x180)
- `icon-192.png` and `icon-512.png` (web manifest)

`npm run check:dist` fails on any other `.jpg/.jpeg/.png/.avif`. Any new image must be converted to WebP first.

## Deploy to Cloudflare Pages

1. Push the repo to the `agencystringhead-wq` GitHub org.
2. In Cloudflare Pages, create a project from the repo.
3. Settings:
   - Framework preset: Astro
   - Build command: `npm run build`
   - Build output directory: `dist`
   - Environment variable: `NODE_VERSION=20`
4. Add the custom domain, then update `site` in `astro.config.mjs` and `url` in `src/data/site.ts`.
